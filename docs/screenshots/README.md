# Screenshots

Place the app screenshots here using these exact filenames so they render in the
main [`README.md`](../../README.md):

| Filename             | Page |
| -------------------- | ---- |
| `home.png`           | Home — hero, categories, featured products |
| `products.png`       | Product listing — grid with search, filter, sort |
| `product-detail.png` | Product detail — image, price, stock, add to cart, related |
| `cart.png`           | Cart — line items, quantity controls, subtotal |
| `wishlist.png`       | Wishlist — saved items with move-to-cart |

To capture them: run `npm run db:create`, `npm run db:seed`, then `npm run dev`,
open http://localhost:3000, and save a screenshot of each page here.
